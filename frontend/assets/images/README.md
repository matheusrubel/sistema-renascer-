# Imagens do sistema

Coloque nesta pasta as imagens usadas pelas páginas do sistema. O servidor disponibiliza arquivos PNG, JPG, JPEG, WEBP, GIF, SVG e ICO com nomes contendo letras, números, ponto, hífen ou sublinhado.

Exemplo de uso no HTML:

```html
<img src="/assets/images/nome-da-imagem.png" alt="Descrição da imagem" />
```

A logo institucional fica diretamente em `frontend/assets/logo-renascer.png`.
